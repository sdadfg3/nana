# مطالعه تخصصی IP در شبکه‌های مخابراتی

گزارش فارسی درباره مبانی IP، معماری مخابرات، امنیت و VPN برای مهندسان شبکه.

## نسخه جدید با قلم بی‌نازنین

این نسخه بر پایه متن مرجع ارسالی و با حفظ ساختار پنج‌فصلی آن تهیه شده است: ۴۰ صفحه، متن فارسی بی‌نازنین ۱۴، متن لاتین Times New Roman، شش جدول مقایسه، چهار نمودار و فهرست صفحه‌دار. قلم‌های لازم در Word جاسازی شده‌اند.
